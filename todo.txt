# Overview
this is a workflow editor app. it will contain LiteGraph.js for UI and spawn commands, either docker or local to run commands.


# Features
- [x] integrate LiteGraph.js
- [x] feedback from backend execution to frontend
- [x] add nodes/plugins

- [x] define custom plugin format to have "run command" and "ui config" for LiteGraph.js
- [x] add LITE plugin

- [x] write simple parser LITE -> LiteGraph.js
- [x] add types: number, string, boolean
- [x] add types: directory
- [x] add conditional inputs within nodes

- [ ] save and load graph state to/from file

- [ ] allow docker image id instead of command, and build command dynamically including volumes

- [ ] add run button to execute the graph

- [ ] add example ICT plugin
- [ ] write parser ICT -> LiteGraph.js
- [ ] add example WIPP plugin
- [ ] write parser WIPP -> LiteGraph.js

- [ ] compile graph to steps logic
- [ ] run steps logic

- [ ] remove nodes that can't be used in the UI
- [ ] store imported plugins somewhere (local or db?)
- [ ] create plugins registry somewhere, or ship it with the app
- [ ] support ICT, WIPP, and custom format plugins
- [ ] export to CWL, WIC, Argo and other workflow formats
